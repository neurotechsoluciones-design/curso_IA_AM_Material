01 / Antes de empezar

Qué necesitás tener a mano

La ruta está pensada para equipos Windows. Si trabajás con macOS o Linux, los enlaces oficiales permiten elegir el instalador correspondiente.

01 / EQUIPO
Windows 10 u 11Preferentemente 64 bits y actualizado.
02 / CONEXIÓN
Internet establePara descargas, autenticación y servicios en la nube.
03 / ACCESO
Permisos de instalaciónAlgunas herramientas pueden requerir autorización del administrador.
04 / CUENTAS
Correo de uso personalPara crear cuentas en GitHub y los servicios que utilice el curso.
!

No instales todo por las dudas. Primero completá la ruta principal. Docker, bases de datos y automatización de navegador se incorporan cuando el ejercicio lo necesita. Para trabajar con datos reales de una empresa, utilizá únicamente accesos autorizados y datos de prueba durante las prácticas.

VS

1. Visual Studio Code

Tu espacio de trabajo para abrir carpetas, archivos y proyectos.

Base
Descarga oficial
Descargar VS Code ↗
  1. Entrá al sitio oficial y seleccioná Windows.
  2. Elegí User Installer x64 para una instalación habitual.
  3. Ejecutá el archivo descargado y aceptá las opciones recomendadas.
  4. Abrí Visual Studio Code desde el menú Inicio.

No necesitás instalar extensiones ahora. Las agregaremos cuando el proyecto las requiera.

Git

2. Git para Windows

Registra cambios y permite volver a versiones anteriores de tus proyectos.

Base
Descarga oficial
Descargar Git ↗
  1. Descargá el instalador para Windows de acuerdo con tu procesador.
  2. Ejecutalo y conservá las opciones recomendadas.
  3. Finalizá la instalación. Git Bash se incluye en Git for Windows.
  4. Abrí PowerShell y comprobá que Git responde.
git --version
GH

3. Cuenta de GitHub

Tu espacio para guardar, versionar y compartir proyectos.

Base
Crear cuenta
Crear cuenta gratuita ↗
  1. Registrate con tu correo habitual y verificá la dirección.
  2. Elegí un nombre de usuario que puedas compartir profesionalmente.
  3. Activá la autenticación en dos pasos.
  4. Conservá tus datos de acceso en un gestor seguro. No compartas tokens.

Git es el programa que controla versiones. GitHub es el servicio en línea donde alojás repositorios. Son complementarios, no lo mismo.

JS

4. Node.js + npm

Permite ejecutar herramientas JavaScript y administrar paquetes.

Base
Descarga oficial
Descargar Node.js ↗
  1. Entrá al sitio oficial y elegí la versión LTS, no la versión Current.
  2. Descargá el instalador Windows x64 (.msi).
  3. Ejecutalo con las opciones predeterminadas. npm se instala junto con Node.js.
  4. Cerrá y volvé a abrir PowerShell o la terminal de VS Code.
node -v
npm -v

La versión LTS es la recomendada para el entorno del curso. No necesitás instalar npm por separado.

Py

5. Python

Para scripts, procesamiento de datos, lógica y agentes desarrollados con código.

Base
Descarga oficial
Descargar Python ↗
  1. En la página oficial buscá una versión estable de la rama Python 3.13.x, 64 bits.
  2. Descargá el instalador para Windows y ejecutalo.
  3. Si utilizás el instalador clásico, activá Add Python to PATH antes de instalar.
  4. Terminá la instalación y abrí una terminal nueva.
python --version
py --version

Se propone Python 3.13 por compatibilidad con bibliotecas de automatización. No instales versiones experimentales para las prácticas.

CX

6. ChatGPT para escritorio + Codex

Agente de código para trabajar sobre carpetas, archivos y proyectos.

Principal
Descarga oficial
Descargar ChatGPT ↗
  1. Elegí la descarga para Windows.
  2. Instalá la aplicación e iniciá sesión con tu cuenta de ChatGPT.

Plataforma para diseñar workflows, integrar servicios y orquestar agentes.

Principal

CC

Claude Code

Alternativa a Codex para programación asistida y trabajo agentic.

Alternativa
Documentación oficial ↗
  1. Revisá los requisitos y el método de instalación para Windows.
  2. Abrí PowerShell y ejecutá el instalador oficial.
  3. Completá la autenticación con una cuenta que tenga acceso a Claude Code.
  4. Verificá la instalación y ejecutá claude doctor.
irm https://claude.ai/install.ps1 | iex

No es obligatorio instalar Codex y Claude Code a la vez. Elegí uno como entorno principal y compará el otro si tenés acceso. Pueden existir costos de suscripción o uso de API.

DK

Docker Desktop + WSL 2

Para ejecutar n8n y otros servicios localmente en contenedores.

Avanzado
Descargar Docker Desktop ↗
  1. En Windows, abrí PowerShell como administrador y ejecutá el comando de WSL.
  2. Reiniciá el equipo si Windows lo solicita.
  3. Instalá Docker Desktop y elegí el backend WSL 2 cuando corresponda.
  4. Abrí Docker Desktop y esperá a que el motor indique que está funcionando.
  5. Comprobá la instalación desde PowerShell.
wsl --install
docker --version
docker compose version

Requiere virtualización habilitada y recursos suficientes. Como referencia, Docker documenta 8 GB de RAM como mínimo para el backend WSL 2. Si no cumple tu equipo, utilizá n8n Cloud. Importante para empresas: el uso comercial de Docker Desktop en organizaciones con más de 250 empleados o más de USD 10 millones de ingresos anuales requiere una suscripción paga; verificá siempre los términos vigentes.

SB

Supabase

Base de datos PostgreSQL, autenticación, almacenamiento y backend.

Según proyecto
Crear cuenta y proyecto ↗
  1. Registrate y creá una organización.
  2. Seleccioná New project y elegí un nombre.
  3. Definí una contraseña segura para la base de datos y guardala fuera del código.
  4. Cuando el proyecto esté listo, explorá Table Editor y SQL Editor.
  5. Revisá las políticas de Row Level Security antes de exponer datos.

No necesitás instalar Supabase en la computadora para utilizar el servicio alojado. Las claves secretas nunca deben quedar en el frontend ni en un repositorio público.

PW

Playwright

Automatizar navegadores y procesos web cuando no hay una API adecuada.

Avanzado
Documentación oficial ↗
  1. Primero instalá Node.js y npm siguiendo la ruta principal.
  2. Abrí PowerShell en la carpeta donde quieras crear el proyecto.
  3. Ejecutá el inicializador y elegí JavaScript o TypeScript.

04 / Conceptos que no se descargan

No confundas protocolo, archivo y programa

Estos elementos se configuran o se construyen durante el curso. No busques un instalador genérico para cada uno.

MCP

Protocolo que estandariza la conexión entre un cliente de IA y herramientas o fuentes externas. Se configura según el agente y el servicio.

Skills

Procedimientos reutilizables que indican cómo realizar una tarea. Pueden incluir instrucciones, ejemplos y recursos.

API y webhooks

Mecanismos para intercambiar información y disparar acciones entre aplicaciones. Se usan desde código o plataformas como n8n.

RAG

Una arquitectura para recuperar información relevante desde fuentes documentales o bases de conocimiento. Se implementa cuando el caso lo requiere.

Agentes y subagentes

Componentes de una arquitectura de trabajo. Se diseñan con objetivos, contexto, herramientas, límites y criterios de revisión.

Credenciales

Accesos y claves que habilitan integraciones. Se gestionan con permisos mínimos y almacenamiento seguro, nunca dentro de prompts públicos.

05 / Control de instalación

Verificá tu entorno

Cuando termines la ruta principal, abrí PowerShell o la terminal de VS Code y ejecutá estos comandos.

COMPROBACIÓN GENERAL

Copiá el bloque completo. Cada línea debería devolver una versión, no un mensaje de comando desconocido.

git --version
node -v
npm -v
python --version
py --version
Configuración inicial de Git

Reemplazá los datos de ejemplo por tu nombre y el correo que vas a utilizar en GitHub.

git config --global user.name "Nombre Apellido"
git config --global user.email "tu-correo@ejemplo.com"
i

Si un comando no se reconoce: cerrá y volvé a abrir la terminal. Si continúa el problema, revisá que la instalación haya terminado y que el programa esté agregado al PATH. No ejecutes scripts de origen desconocido ni cambies políticas de seguridad sin comprender el efecto.

07 / Buenas prácticas

Antes de conectar sistemas de una empresa

Instalar una herramienta no significa que esté lista para operar con información sensible o procesos de producción.

01
Protegé las clavesNo pegues API keys, tokens ni contraseñas en prompts, capturas o repositorios.
02
Usá datos ficticiosProbá primero con información de ejemplo, no con bases reales de clientes.
03
Limitá los permisosEmpezá con acceso de lectura. Habilitá escritura solo cuando sea necesario.
04
Revisá antes de ejecutarPedí aprobación humana para pagos, envíos, borrados y acciones irreversibles.
05
Auditá las extensionesRevisá el origen y los permisos de MCP, plugins y paquetes comunitarios antes de instalarlos.
06
Versioná los proyectosUsá Git y mantené separados desarrollo y producción. Conservá una forma de volver atrás.
